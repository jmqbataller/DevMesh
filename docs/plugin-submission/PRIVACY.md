# DevMesh Privacy Policy

Effective date: August 11, 2026

DevMesh is an open-source, skills-only software engineering workflow plugin distributed from the public `jmqbataller/DevMesh` GitHub repository.

## What DevMesh itself collects

The DevMesh skills package does not operate a DevMesh-controlled backend service, analytics service, account system, telemetry endpoint, advertising system, or user database. Installing or invoking the skills-only plugin does not by itself send conversation content, source code, repository data, files, credentials, or personal information to a server operated by DevMesh.

## Data processed by ChatGPT, Codex, and connected tools

DevMesh provides workflow instructions that may cause ChatGPT or Codex to use capabilities available in the user's environment, such as uploaded files, code execution, browser automation, GitHub, deployment services, or other connected apps. Any data processed through those products and services is handled by the applicable provider under that provider's terms, privacy policy, permissions, and workspace controls.

DevMesh does not expand the permissions of ChatGPT, Codex, GitHub, or any connected app. Users and workspace administrators remain in control of connections and permissions offered by those services.

## Sensitive data

DevMesh instructions explicitly discourage exposing or persisting secrets such as API keys, passwords, tokens, cookies, private keys, service-role keys, or `.env` values in chat output, reports, fixtures, logs, or project memory.

Users should not place sensitive information in public GitHub issues or other public support channels.

## Sale or advertising use of data

DevMesh does not sell personal data and does not operate an advertising or profiling service.

## Cookies and tracking

The DevMesh skills-only plugin does not set cookies or run independent tracking technologies. The websites and platforms used to distribute or execute DevMesh, including GitHub and OpenAI products, may use their own cookies or telemetry under their respective policies.

## Open-source repository

Source code, documentation, issues, pull requests, discussions, and other contributions made publicly in the DevMesh GitHub repository are public according to GitHub's platform behavior and policies.

## Security

DevMesh is designed around least-assumption and evidence boundaries, including rules against secret exposure and false execution claims. No software or workflow can guarantee complete security. Users should review generated code and actions before using them in sensitive or production environments.

## Changes

This policy may be updated when DevMesh functionality, distribution, or data handling changes. Material changes will be reflected in this document and repository history.

## Contact

For privacy questions about DevMesh, use the repository's public support channel:

https://github.com/jmqbataller/DevMesh/issues

Do not include passwords, access tokens, private source code, or other sensitive information in a public issue.
